# История DroneLab Physics Packages

## 0.3.3 — 2026-10-06

- Ветка physics-packages для улучшения/выпуска SDK; основа — актуальная physics-plugins, пользовательская очистка проекта сохранена.
- Пользовательский фикс `.1f` в DescentWindRigidbodyTests сохранён и включён в экспорт Demo.
- POSIX-ключи файлов и папок на Windows/Linux; Documentation~ не требует .meta.
- UTF-8 без BOM и LF в экспорте/генераторах; CRLF checkout не меняет канонические hashes/GUID. Кириллица и пробелы в путях покрыты регрессиями.
- Проверка всех обязательных source-папок до записи пакетов; отсутствие исходников не даёт выпустить молча неполный SDK.
- Отдельные README Physics/Demo, README ветки, руководство разработчика, таблицы физических величин и актуализированный справочник всех формул.
- .NET test project копирует вложенные benchmark JSON; добавлен Windows/Ubuntu CI для пакетов, Python, .NET и генерации контракта.
- Уравнения физики, JSON 1.0.0 и CSV 1.4.0 не изменены. Unity PlayMode/import/EXE проверяются отдельно.
