## Установка MD-комплекта

ZIP содержит только Markdown. Пути внутри него заданы **от корня Unity-репозитория**: главный файл расположен в `README.md`, руководства — в `Docs`, локальные описания ресурсов — в соответствующих каталогах `Assets`.

1. Распакуйте архив в корень своей рабочей копии проекта. Файлы с совпадающими путями заменяют прежние руководства.
2. Проверьте главный README и переходы в `Docs/README.md`.
3. Выполните из корня:

```bash
python Tools/build_unity_packages.py
python Tools/build_environment_package.py
python Tools/build_unity_packages.py --check
python Tools/build_environment_package.py --check
```

Генераторы обновят Markdown-копии и хеши экспортируемых пакетов. Эти производные файлы не включены в MD-архив: актуальный экспорт создаётся из вашей полной рабочей копии. Сохраните в Git документацию и связанные изменения в `Distribution/Packages` вместе.

Комплект не меняет C#, JSON-схемы, сцены, тесты или настройки сборки. `PARAMETERS.md` сохраняет сгенерированный контракт; `AGENTS.md` не относится к пользовательской документации и в архив не входит.

## Где хранить сведения

| Сведения | Единственный подробный документ |

| Форк, расширение приложения, сборка | `Docs/DEVELOPMENT.md` |
| Слои и технические решения | `Docs/ARCHITECTURE.md` |
| Команды тестов и ручная приёмка | `Docs/TESTING.md` |
| Физические уравнения и их применимость | `Docs/Physics/PHYSICS_REFERENCE.md` |

В соседних файлах допускается короткое объяснение и ссылка на владельца темы. Формулы, инструкции и численные таблицы целиком не копируются между руководствами.

[SCENARIOS_AND_ENVIRONMENT_CONCEPT.md](UI/SCENARIOS_AND_ENVIRONMENT_CONCEPT.md) и [README_DRONELAB_RU.md](../README_DRONELAB_RU.md) оставлены как короткие переходы. Их содержимое не нужно развивать параллельно с основными страницами.

## Сгенерированные документы

`PARAMETERS.md` создаётся `Tools/generate_physics_contract.py`. Изменения полей вносятся в генератор, затем одновременно обновляются DTO, обе схемы и реестр.

[PHYSICS_PACKAGE_README.md](Physics/PHYSICS_PACKAGE_README.md) и [DEMO_PACKAGE_README.md](Physics/DEMO_PACKAGE_README.md) служат источниками корневых README пакетов. Остальные физические руководства и данные копируются в `Documentation~` при экспорте. Описания среды в `Assets/DroneEnvironment` также имеют свои производные копии в пакете среды.

Ссылки внутри физического раздела должны работать и после экспорта. Общие руководства приложения из документов пакета доступны по URL исходного репозитория; ссылки на формулы, параметры и данные остаются относительными.
