# Сценарии и окружение

Первоначальный вариант с одновременным выбором карты и погоды заменён двумя независимыми разделами по уточнённому референсу.

Реализация и настройка: [SCENARIOS_AND_ENVIRONMENT.md](SCENARIOS_AND_ENVIRONMENT.md).

В «Картах» только галерея, поиск и фильтр; в «Профилях среды» библиотека и полный редактор. Карты не привязаны к профилям. Комбинация выбирается отдельно при запуске «Новой симуляции».
