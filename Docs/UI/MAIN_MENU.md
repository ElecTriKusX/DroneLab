# Главное меню Дронлаб · 0.1.2

Unity UI Toolkit, готовая сцена `Assets/Scenes/MainMenu.unity` в ветке `physics-packages`. После получения изменений откройте эту сцену и нажмите Play. Фон уже назначен, сцены включены в общий список сборки; Editor-команды для настройки не нужны. Локальный Build Profile с Override Global Scene List должен включать MainMenu и PhysTest либо использовать общий список.

## Главное меню

Названия и порядок соответствуют предоставленному референсу:

1. НОВАЯ СИМУЛЯЦИЯ
2. КАТАЛОГ ДРОНОВ
3. СЦЕНАРИИ И ОКРУЖЕНИЕ
4. ЛАБОРАТОРИЯ
5. НАСТРОЙКИ
6. СПРАВКА / О ПРОГРАММЕ
7. ВЫХОД

В каждом пункте — контурная иконка слева, надпись с выравниванием по левому краю и стрелка справа. Перед тремя нижними пунктами — линия и небольшой отступ. Скруглённые тонкие рамки, состояния hover/focus/pressed; первый пункт выделен яркой обводкой. Иконки рисуются векторно через Painter2D, не требуют шрифта с пиктограммами или картинок.

Базовая область 1920×1080 масштабируется вместе с фоном с сохранением пропорций. При другом соотношении сторон появляются чёрные поля. Оформление находится в `Assets/DroneUI/Resources/DroneLab/MainMenu.uss`.

«Новая симуляция» загружает Flight Scene (PhysTest). Три следующих экрана подключаются событиями Configure Drone, Scenarios и Laboratory в Inspector; пока обработчиков нет, выводится сообщение о разработке экрана. Их внутреннее содержимое в этом изменении не реализуется.

## Выход

Диалог «Вы точно хотите выйти?»: «Назад» слева, «Выйти» справа. Первоначальный фокус — на «Назад». Escape закрывает окно, не завершает приложение. Пока открыт диалог, основное меню отключено, поэтому нельзя случайно нажать кнопку за окном. После закрытия фокус возвращается к исходному пункту. В Unity выход останавливает Play Mode, в сборке завершает приложение.

## Справка / о программе

Русский текст о демонстрации техники и предварительных инженерных испытаниях, четыре преимущества, состав разработчиков и версия 0.1.2. Перечень преимуществ описывает назначение платформы; он не является проверкой готовности всех её подсистем. Раздел имеет прокрутку, чтобы текст не обрезался.

В компоненте Drone Main Menu → Developer Links можно задать необязательный URL напротив каждого имени. Пустая ссылка показывает обычный текст; HTTP/HTTPS-ссылка делает имя кнопкой, открывающей страницу во внешнем браузере. Другие схемы не открываются. Имена:

- Матвиенко А. В.
- Якубовский Д. А.
- Поляков И. М.
- Николаев С. Н.

Версия интерфейса задаётся полем Version = 0.1.2. Общий ProjectSettings.asset этим изменением не обновляется.

## Настройки

- Громкость окружающей среды: общий множитель для ambient/weather/thunder Enviro 3, с процентным значением.
- Громкость дрона / лопастей: независимый множитель существующих AudioSource под дроном.
- Полный экран.
- Устройство управления: клавиатура или геймпад; при отсутствии геймпада показывается подсказка.
- Пресет качества: реальные уровни проекта High Fidelity / Balanced / Performant, отображаемые по-русски.
- Вертикальная синхронизация (VSync).

Изменения действуют после «Применить». «Назад» и Escape отменяют черновик. Настройки сохраняются в PlayerPrefs отдельным JSON-ключом `DroneLab.ApplicationSettings.v1` и загружаются при следующем запуске меню. Качество применяется раньше VSync, поскольку Unity может сбросить VSync при выборе уровня качества.

`DroneApplicationSettings` живёт между сменами сцен. Он применяет выбор устройства к настоящему `DroneTestPilot.inputDevice`, включая дроны, созданные после загрузки. При выборе отсутствующего геймпада автозамена на клавиатуру не выполняется: пилот использует штатное поведение при недоступности устройства.

Enviro подключается через `EnviroManager.instance.Audio`. Создаётся отдельный runtime-контейнер аудионастроек с исходными списками звуков; коэффициенты громкости и модификаторы масштабируются без изменения исходного контейнера настроек и пресетов. Исходные ссылки и модификаторы восстанавливаются при уничтожении сервиса. Это учитывает разную формулу громкости грома и остальных звуков в Enviro 3.

Звук лопастей должен существовать как AudioSource: настройка не генерирует аудиоклип. В текущем PhysTest готовые AudioSource дрона отсутствуют. При появлении источников под `DroneTestPilot` автоматически подключается `DroneAudioVolume`; его также можно добавить вручную и назначить конкретные Sources. Если будущий контроллер звука динамически меняет громкость от RPM, передавайте исходную громкость через `DroneAudioVolume.SetBaseVolume(index, value)`, чтобы сохранить множитель пользователя. Высота тона и физика моторов не меняются.

## Проверка

В рабочем окружении выполнены разбор C# синтаксическим парсером, проверки Unity YAML, GUID и метафайлов, ссылок сцены и списка сборки. Семантическая компиляция Unity, Play Mode и визуальное сравнение не выполнялись: Unity Editor здесь отсутствует.

В Unity проверьте расположение меню в Game View 1920×1080 и 2560×1440, затем все три окна, навигацию Tab/Enter/Escape, отмену и сохранение настроек, загрузку PhysTest и выбор геймпада. Для проверки звука нужен включённый Enviro Audio Module с назначенными клипами и AudioSource дрона.


## Доводка контролов

Полный экран и VSync выбираются выпадающими списками «Включено / Выключено». Выбранные значения имеют шрифт 18 px, пункты открытого списка — 16 px. Обычные подписи не выделяются и не принимают клики; кнопки и необязательные ссылки разработчиков остаются интерактивными.

В справке и настройках используется штатный ScrollView с графитовой дорожкой и округлым прямоугольным бегунком чуть светлее фона. Кнопки-стрелки прокрутки скрыты. Перетаскивание, колесо мыши и клавиатурная навигация сохраняются. Эти изменения прошли статическую проверку; внешний вид и взаимодействия ещё требуют запуска Unity.
