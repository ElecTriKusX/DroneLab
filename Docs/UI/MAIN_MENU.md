# Главное меню DroneLab

Реализация в `Assets/DroneUI`, Unity UI Toolkit. Физика и её документация не изменены.

## Запуск готовой сцены

1. Получите последние изменения `physics-packages` и дождитесь импорта Unity.
2. Откройте `Assets/Scenes/MainMenu.unity` и нажмите Play.
3. Нажмите «Начать испытание» — загружается `PhysTest`.

Фон уже назначен сериализованной ссылкой в сцене. MainMenu стоит первой в общем списке сборки, PhysTest — второй; отсутствующая DimaScene удалена из списка. Создавать сцену, перетаскивать картинку и запускать **Add Menu and PhysTest to Build** не требуется. Камера меню очищает экран; UI Toolkit рисует интерфейс поверх неё.

Профили сборки с собственным Override Global Scene List в репозитории отсутствуют. Если такой профиль существует только локально, он использует свой список вместо общего: отключите Override Global Scene List для использования сохранённого списка проекта.

`Background`, `Menu Font`, `Developers` и `Flight Scene` можно менять в Inspector при последующей настройке.

## Поведение

- Начать испытание: асинхронная загрузка заданной сцены. При отсутствии сцены в сборке выводится сообщение; повторные клики при загрузке блокируются.
- Конфигуратор: событие **Configure Drone** в Inspector для подключения будущего UI. Пока обработчик не назначен, выводится пояснение; готовый конфигуратор не имитируется.
- Настройки: громкость (сохраняется между запусками), полный экран и уровень качества (применяются на текущий запуск). Изменение качества использует уровни проекта — настройте их HDRP-ассеты заранее.
- О проекте: редактируемый состав разработчиков, версия из Player Settings.
- Выход: подтверждение; в редакторе останавливает Play Mode.
- Tab/Shift+Tab и Enter: стандартная навигация UI Toolkit. Escape закрывает диалог или открывает подтверждение выхода, когда UI имеет фокус.

## Оформление

Базовая область 1920×1080 масштабируется целиком с сохранением пропорций. На иных соотношениях сторон остаются чёрные поля, чтобы чертежи и логотип не обрезались. Центральная колонка: 620 px, кнопки 70 px, промежутки 18 px. Тонкая непрерывная светлая обводка, усиленная обводка первого пункта, графитовая заливка, увеличенный межбуквенный интервал, подсветка hover/focus и инверсия при нажатии. Все размеры и цвета доступны в `Resources/DroneLab/MainMenu.uss`.

Фон из `Assets/DroneUI/Runtime/DronaLab background.png` включён в Git и назначен в сцене; импорт — Default, без mipmaps и сжатия, Max Size 4096. Без фона появляется временный текстовый логотип. Изображение без кнопок позволяет сохранить окружение точно, но исходная геометрия удалённых кнопок в нём отсутствует: размеры и надписи кнопок — восстановленная компоновка, а не подтверждённое совпадение пиксель в пиксель.

## Проверка

Проверены сериализованные ссылки сцены на скрипт и фон, GUID сцен в списке сборки, наличие включённых сцен в репозитории и отсутствие лишнего SpriteRenderer. Unity Editor в рабочем окружении отсутствует: компиляция Unity, Play Mode и визуальное сравнение ещё не выполнены. Проверьте в Game View 1920×1080 и 2560×1440, затем на широком экране: фон, рамки, hover/focus, диалоги и загрузку Flight Scene.
