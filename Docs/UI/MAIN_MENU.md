# Главное меню DroneLab

Реализация в `Assets/DroneUI`, Unity UI Toolkit. Физика и её документация не изменены.

## Установка

1. Переключитесь на `physics-packages`, получите последний коммит и дождитесь компиляции Unity.
2. Выполните **DroneLab → UI → Create Main Menu Scene**. Инструмент создаст и сохранит `Assets/Scenes/MainMenu.unity`. Если сцена уже существует, он откроет её без перезаписи.
3. Выберите **DroneLab Main Menu** в Hierarchy.
4. Импортируйте вашу картинку без центральных кнопок в Assets. Оставьте Texture Type = Default, Max Size = 4096 или выше, Compression = None. Перетащите её в **Background** компонента Drone Main Menu. В самой картинке уже есть логотип и чертежи; они повторно не рисуются.
5. При необходимости назначьте **Menu Font**: обычный Font с кириллицей. Укажите **Developers** и **Flight Scene** (по умолчанию `PhysTest`).
6. Сохраните сцену. Выполните **DroneLab → UI → Add Menu and PhysTest to Build**, либо добавьте сцены вручную в активном **Build Profiles → Scene List**: MainMenu первой, затем вашу сцену полёта. В профилях с Override Global Scene List настройте список этого профиля вручную.
7. Нажмите Play.

## Поведение

- Начать испытание: асинхронная загрузка заданной сцены. При отсутствии сцены в сборке выводится сообщение; повторные клики при загрузке блокируются.
- Конфигуратор: событие **Configure Drone** в Inspector для подключения будущего UI. Пока обработчик не назначен, выводится пояснение; готовый конфигуратор не имитируется.
- Настройки: громкость (сохраняется между запусками), полный экран и уровень качества (применяются на текущий запуск). Изменение качества использует уровни проекта — настройте их HDRP-ассеты заранее.
- О проекте: редактируемый состав разработчиков, версия из Player Settings.
- Выход: подтверждение; в редакторе останавливает Play Mode.
- Tab/Shift+Tab и Enter: стандартная навигация UI Toolkit. Escape закрывает диалог или открывает подтверждение выхода, когда UI имеет фокус.

## Оформление

Базовая область 1920×1080 масштабируется целиком с сохранением пропорций. На иных соотношениях сторон остаются чёрные поля, чтобы чертежи и логотип не обрезались. Центральная колонка: 620 px, кнопки 70 px, промежутки 18 px. Тонкая непрерывная светлая обводка, усиленная обводка первого пункта, графитовая заливка, увеличенный межбуквенный интервал, подсветка hover/focus и инверсия при нажатии. Все размеры и цвета доступны в `Resources/DroneLab/MainMenu.uss`.

Фон подключается вручную и не включён в Git по просьбе пользователя. Без фона появляется временный текстовый логотип. Изображение без кнопок позволяет сохранить окружение точно, но исходная геометрия удалённых кнопок в нём отсутствует: размеры и надписи кнопок — восстановленная компоновка, а не подтверждённое совпадение пиксель в пиксель.

## Проверка

Проведены статическая проверка новых файлов и проверка Unity meta-файлов. Unity Editor в рабочем окружении отсутствует: компиляция Unity, Play Mode и визуальное сравнение ещё не выполнены. Проверьте в Game View 1920×1080 и 2560×1440, затем на широком экране: фон, рамки, hover/focus, диалоги и загрузку Flight Scene.
