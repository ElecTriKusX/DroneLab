# Запуск симуляции из главного меню

Изменения рассчитаны на ветку `physics-packages`, исходный коммит `2df03a4`.
Архив содержит только изменения и новые файлы с путями от корня проекта и `.meta`.

## Установка

1. Закройте Unity и распакуйте ZIP в корень проекта: рядом с `Assets`, `Packages`, `ProjectSettings`.
2. Откройте проект и дождитесь компиляции. Обновлять каталог, импортировать модели или создавать новые профили для запуска не нужно.
3. Откройте `Assets/Scenes/Forest.unity`, выберите свою посадочную площадку в Hierarchy.
4. Выполните `DroneLab → Simulation → Add Spawn Point to Selected Pad`.
5. Появится дочерний объект `DroneLab Spawn Point` с компонентом `DroneSpawnPoint`. Поставьте его в свободное место **на верхней поверхности** площадки. Меню оценивает верх по Collider/Renderer; для сложной или наклонной модели уточните точку вручную.
6. Поворот Y задаёт направление носа дрона (+Z). X/Z точки влияют только на её положение; наклон площадки не наклоняет аппарат. `Clearance M` — зазор под физическим корпусом, по умолчанию 0,03 м. Половина высоты корпуса добавляется автоматически.
7. У площадки должен быть включённый Collider, который не является Trigger. Для наклонной поверхности увеличьте зазор или выберите горизонтальную часть площадки.
8. Сохраните сцену. Откройте `Assets/Scenes/MainMenu.unity` и нажмите Play → «Новая симуляция».

В текущей Git-версии Forest конкретная пользовательская площадка не определена.
Этот ZIP не заменяет Forest и не меняет локальную модель площадки: точку нужно назначить на вашей сцене один раз.

## Выбор перед полётом

- Шаг 01 — существующий каталог дронов, поиск и фильтр по категориям/меткам. Доступны только готовые сохранённые профили. Выделите карточку и нажмите «Выбрать дрон»; Enter или двойной щелчок также переходят дальше. Создание, импорт, экспорт, редактирование, копирование и удаление доступны в отдельном каталоге главного меню.
- Шаг 02 — карты в две колонки слева, профили погоды и среды справа. У карт и погоды независимый поиск. Итоговый выбор виден над кнопками.
- «Назад» и Esc на шаге 02 возвращают к выбору дрона, сохраняя выбранную карту и погоду. На шаге 01 они возвращают в главное меню. Последние принятые параметры запоминаются между запусками.
- «Начать симуляцию» проверяет сочетание профилей, модель и возможность управления, затем загружает сцену. Отсутствующая в сборке карта не запускается.

Погодная галерея использует **сохранённые профили среды**: они содержат одновременно ветер, атмосферу, погоду и время, как в разделе «Сценарии и окружение».

## Несколько стартовых площадок

Каждой точке задайте уникальный `Id`, например `main`, `north`, `roof`.
Откройте `DroneLab → UI → Open Maps and Environment Catalog` и в записи карты
впишите нужный `Точка старта · Id`.

При единственной активной точке это поле можно оставить пустым. При нескольких точках
пустое поле вызывает понятную ошибку: система не выбирает случайную площадку.
Неактивные/выключенные точки и объекты из другой сцены не участвуют в выборе.

## Что создаётся при запуске

Создаётся один новый дрон с выбранными профилем, GLB/glTF и настройками привязки роторов.
В карте заранее размещать тестовый DronePhysicsBody не требуется. Старые тестовые
дроны на этой карте деактивируются в текущем запуске. Unity-сцена на диске не меняется.
Корень физики имеет единичный масштаб, визуальная модель — масштаб и ориентацию из профиля.
Столкновения используют физический BoxCollider по `dimensionsM`, а не детальный mesh модели.
Точка старта проверяется на пересечение корпуса с препятствиями.

Существующая игровая камера сохраняет настройки HDRP, следует за выбранным дроном;
штатный FreeCamera-контроллер Forest выключается во время полёта. Погодная система
также получает эту камеру и дрон как объект следования. Над полётом добавлена
небольшая панель в графитовом стиле и подсказка управления.

## Управление

| Кнопка | Действие |
|---|---|
| F | Включить/выключить моторы |
| W / S | Тангаж: вперёд / назад |
| A / D | Крен: влево / вправо |
| Q / E | Рыскание |
| Space | Тяга вверх; при удержании высоты — подъём |
| Ctrl | Снижение в режиме удержания высоты |
| H | Удержание высоты |
| Z | Стабилизация / ручной режим |
| Backspace | Вернуться в исходную позу на стартовой площадке, моторы выключены |
| Esc | Пауза, продолжение или возврат в главное меню |

При старте моторы выключены. Начальная клавиатурная тяга подбирается по массе и
максимальной тяге профиля. В ручном режиме отпускание Space убирает тягу;
для удержания высоты включите H. Удержание высоты не удерживает X/Z на месте.

## Поддержка роторов и границы

Пилот поддерживает управляемые мультироторные схемы с ≥4 параллельными осями тяги +Y.
Четыре ротора сохраняют прежнее распределение. Для N>4 добавлен MultirotorAllocator;
встроенный шестироторный DJI M600 проходит проверку инициализации.
Самолётные схемы, наклонные оси и вырожденные раскладки отклоняются до загрузки карты.
Это не автоматическая настройка PID под любую раму и не контроллер компенсации отказов.

Для дрона без загруженной модели остаётся схематический визуальный корпус. Если
импорт GLB завершается ошибкой уже после начала сцены, причина пишется в Console,
а физический корпус остаётся доступен. Совместимость внешнего воздуха и плотности
проверяется прежним валидатором: измеренные силы не масштабируются скрытно.

## Проверки этой версии

- 512 тестов математической физики — пройдены, включая новые проверки 6/8 роторов, совместных моментов, насыщения и сохранения результатов четырёхроторного allocator.
- 86 тестов конфигуратора — пройдены, включая инициализацию pilot для всех готовых встроенных профилей и сохранение пакетов моделей.
- Проверка синтаксиса изменённых C# файлов — выполнена.
- Добавлены Unity EditMode-тесты выбора точки старта, дубликатов, неактивных точек, высоты и зазора.
- Unity Editor/Play Mode здесь не запускался: визуальную раскладку, HDRP-камеру, импорт выбранной GLB и полёт в Forest нужно проверить в вашем Unity.

Быстрая проверка в Unity: выбрать DJI → выбрать «Лес» и спокойную погоду → запуск →
проверить положение на площадке → F + Space → H → Esc → продолжить → Backspace →
Esc → главное меню → повторить с другим дроном и погодой.
