# Карты и профили среды

Рабочая реализация вкладки «Сценарии и окружение» в главном меню. Два независимых раздела: галерея карт и библиотека профилей. Карта не содержит ссылки на профиль среды. В заголовке ДРОНЛАБ нет иконки. Графит, тонкие обводки, левое выравнивание, компактные списки, собственный графитовый scrollbar; вся страница масштабируется вместе с меню от 1920×1080.

## Карты и скриншоты

Откройте **DroneLab → UI → Open Maps and Environment Catalog**. Это `Assets/DroneUI/Resources/DroneLab/ScenarioCatalog.asset`; другой каталог можно назначить в поле Scenario Catalog компонента DroneMainMenu.

Каждая запись хранит стабильный id, название, тип местности, размер в **метрах**, Texture2D скриншота и SceneAsset (Inspector сохраняет путь сцены). Название находится поверх превью, под изображением — только тип и размеры. Панели подробностей и запуска в галерее нет. Поиск и фильтр работают по каталогу. Картинка не влияет на сцену, физику или погоду.

Скриншоты складывайте в **Assets/DroneUI/Screenshots/Maps** и перетаскивайте в поле Screenshot нужной карты. Рекомендуется PNG/JPG 16:9. Превью погодных пресетов — **Assets/DroneUI/Screenshots/Weather**. Рисованных изображений несуществующих карт в каталог не добавлено: начальные записи — реальные Forest и PhysTest, пока с нейтральным placeholder. Размер 0 обозначает «Размер не указан»: заполните реальную площадь, она не угадывается из имени сцены.

Новая карта: подготовить сцену в Unity → добавить запись с уникальным id, сценой, размером и скриншотом → **Add catalog maps to Build** → пересобрать приложение. Кнопка **Add scenes from Assets/Scenes** добавляет новые сцены без изменения существующих записей. При первом добавлении автоматически ищет Forest.png / PhysTest.png в папке скриншотов. Добавление внешних игровых сцен на диске клиента пока не реализовано.

## Профили

Все `Resources/DronePhysics/environment_*` появляются как встроенные профили. Их исходники неизменяемы: «Сохранить копию» создаёт пользовательский профиль. Пользовательские записи можно редактировать, удалять с подтверждением, импортировать, экспортировать. Перед сменой вкладки/профиля и выходом предлагается сохранить несохранённые изменения.

Пользовательские профили находятся в `Application.persistentDataPath/DroneLab/EnvironmentProfiles`. Экспорт — подкаталог Exchange. Импорт использует полный путь к JSON, работает в Editor и standalone без Editor API. Поддерживается как обычный JSON физики 1.0.0, так и новый документ:

```json
{
  "documentVersion": 1,
  "id": "<guid>",
  "name": "Боковой ветер",
  "environment": { "schemaVersion": "1.0.0", "...": "полный исходный контракт физики" },
  "visual": { "weatherPresetId": "<asset-guid>", "timeOfDay": 14, "simulateTime": false }
}
```

Это иллюстрация структуры, не готовый physics JSON. Схема физики не изменена. Visual настройки находятся снаружи environment. Сохраняются все поля окружения, включая неактивные дополнительные параметры. Профиль проходит оригинальные ContractValidator/ProfileLoader; совместимость с фактическим дроном дополнительно проверяется перед его первым Initialize.

Редактор содержит **все поля EnvironmentProfile**: gravityMps2, airDensityMode, airDensityKgM3, temperatureK, pressurePa, altitudeM; все шесть windMode, полный windVelocityWorldMps X/Y/Z, gustEnabled, gustIntensityMps, gustTimeScaleS, turbulenceSeed; weather.precipitation/intensityMmPerHour/model; все семь параметров Dryden, включая тройки RMS, масштабов и оси. schemaVersion/model осадков фиксированы контрактом и показаны как справочные значения.

Основные поля — погода, время, осадки, режим/горизонтальная скорость/направление ветра, температура, модель воздуха. Остальное — «Расширенные параметры». °C переводится в K; давление остаётся в Па, высота в м. Направление «откуда дует» связано с мировыми +Z (север) и +X (восток), вектор не теряет вертикальную компоненту. Для CustomField источником является Enviro или назначенный провайдер, поэтому ручная скорость/направление недоступны.

Значения стандартных физических defaults показаны серым и остаются редактируемыми. Визуальные defaults берутся из выбранного Enviro пресета; серый цвет означает наследование, «Из пресета» удаляет переопределение. При выборе «Из сцены» реальные значения наследуются при запуске; показанные численные defaults без зарегистрированного пресета лишь справочные.

## Enviro и физическая модель

Каталог регистрирует реальные EnviroWeatherType по стабильному AssetDatabase GUID, не по индексу. При первом открытии Unity пустой список заполняется установленными пресетами; дальше **Register Enviro weather presets** только добавляет новые. Названия и превью можно изменить в Inspector, id сохранять.

В профиле можно переопределить визуальную турбулентность растительности, мокроту/снег поверхности, coverage/density облаков; при ENVIRO_HDRP — fog attenuation distance, baseHeight и maxHeight. Драйвер клонирует выбранный погодный preset, не изменяет Enviro assets или настройки Forest на диске. Time module необходим для времени суток, Fog/Clouds/Effects modules — для соответствующих эффектов.

Физическая среда сохраняет приоритет. Constant/Gust/Turbulence/DrydenFrozen используют существующий RuntimeEnvironment без новых сил и без двойного ветра. В Enviro и WindZone передаётся горизонтальная часть того же поля, включая порывы. Вертикальный ветер остаётся физическим: горизонтальная Enviro WindZone его не отображает. Визуальная скорость нормируется через fullStrengthWindMps и насыщается при 1, физический ветер не обрезается. windTurbulence Enviro не заменяет физическую турбулентность/Dryden.

Для CustomField используется существующий EnviroWeatherController/IWindProvider. Источник воздуха для запуска из профиля — именно JSON физики: это сохраняет Constant density и корректный смысл sea-level temperature/pressure в StandardAtmosphere. Нельзя незаметно заменить их LOCAL live-air колонкой Enviro. Драйвер преобразует заданные sea-level значения в локальные для визуального адаптера. В этом режиме редактор не предлагает независимый переключатель live-air; ранее настроенное поведение при прямом открытии сцены сохраняется.

Осадки сохраняют VisualOnly metadata. В типовых эффектах с именами Rain/Snow/Hail emission = clamp(intensityMmPerHour / 20, 0, 1): это **явная демонстрационная шкала**, не калибровка частиц в мм/ч. Для иных имён/града типы эффекта должны быть настроены в самом Enviro preset. Вода/лёд не добавляют силы или массу аппарату.

## Запуск

В «Новой симуляции» карта и профиль выбираются независимо. `DroneScenarioLaunch.Load(map, document, catalog)` загружает полный путь сцены. Новый опциональный PreparingSceneBody hook адаптера исполняется после назначения стандартных TextAsset и до первого Initialize. Он назначает валидированный environment JSON без повторной инициализации летящего дрона. После sceneLoaded отдельный визуальный драйвер ждёт первый валидный Enviro frame и применяет погодную копию/время. Сценарий не хранится в карте, настройки профиля не меняются при просмотре галереи.

Профили переменной атмосферы требуют совместимых CtCq/PerformanceMap роторов. Запуск через Enviro дополнительно проверяет локальную температуру 200–330 К, давление 1000–200000 Па и высоту −500–11000 м. Несовместимые параметры отклоняются с сообщением. Перед стартом сцена должна уже содержать настроенный дрон; каталог не импортирует/не создаёт модель дрона автоматически.

## Проверка в Unity

1. После импорта открыть MainMenu; проверить масштабирование, оба раздела, dropdown без синего выделения, прокрутку и Escape.
2. Назначить скриншоты и размеры Forest/PhysTest в каталоге; проверить поиск/фильтр.
3. Создать копию профиля Gust, задать амплитуду/период; сохранить, перезапустить приложение, экспортировать/импортировать JSON.
4. Запустить совместимую карту/дрон через «Новую симуляцию». Сверить ActiveEnvironmentJson и WindVelocityWorld, порывы WindZone, время, облака/туман. Для CustomField сверить провайдер до Initialize.
5. В Test Runner выполнить DroneLab.UI.Tests; проверить отказ несовместимого measured профиля и импорт некорректных данных.

Unity Editor/Play Mode здесь не запускались. Полноценная визуальная проверка совпадения с референсом и сторонних Enviro modules требует Unity.
