# Сцены и окружающая среда

[Интерфейс](README.md) · [Реестр параметров среды](../Physics/PARAMETERS.md)

## Сцены

Каталог сценариев связывает игровую сцену, её название, превью, размеры и стартовые точки. Система рассчитана на несколько сцен. В текущем проекте используются `MainMenu`, `PhysTest` и `Forest`; дополнительные сцены могут передаваться командой отдельно от репозитория.

При выборе ориентируйтесь на фактический каталог вашей сборки. Для запуска сцена должна быть импортирована и включена в активный Build Profile. Превью служит изображением карточки и не меняет физическую среду.

## Профиль условий

Откройте **«Сценарии и окружение»** или шаг выбора сцены в **«Новая симуляция»**. Выберите готовый профиль либо создайте собственный. Для первого полёта удобно использовать спокойные условия, затем отдельно менять ветер и оборудование.

| Группа | Настраиваемые данные |
|---|---|
| Визуальная погода | Погодный пресет, время суток, облака, туман, осадки и состояние поверхности |
| Воздух | Модель плотности, температура, давление, высота, постоянная плотность при выбранном режиме |
| Гравитация | Ускорение свободного падения |
| Ветер | Режим, мировой вектор, горизонтальная скорость и направление |
| Порывы | Включение, интенсивность и временной масштаб |
| Турбулентность | Seed и параметры выбранной модели |
| DrydenFrozen | RMS-компоненты, масштабы, ось и параметры спектрального поля |

Основные поля показаны сразу, специальные — в расширенных параметрах. Температура °C переводится в K; давление задаётся в Па, расстояния — в метрах, скорость — в м/с. Строгие поля JSON и их диапазоны находятся в [PARAMETERS.md](../Physics/PARAMETERS.md).

## Направление и режимы ветра

Число градусов означает **откуда дует**: 0° — с севера, 90° — с востока. Мировые +Z и +X соответствуют северу и востоку. Поэтому западный ветер 4 м/с имеет вектор `[4,0,0]`. Полный вектор также может содержать вертикальную компоненту.

| Режим | Поведение |
|---|---|
| None | Ветер выключен |
| Constant | Однородный средний поток |
| Gust | Средний поток с периодическими порывами |
| Turbulence | Ограниченное воспроизводимое гармоническое поле |
| DrydenFrozen | Спектральное поле по модели Dryden с фиксированным seed |
| CustomField | Пространственный источник сцены через `IWindProvider` |

Режимы взаимоисключающие. Порывы могут дополнительно накладываться на Constant, Turbulence и DrydenFrozen; в Gust они обязательны, в None/CustomField выключены. При простых порывах и Turbulence часть параметров интенсивности/времени используется обоими механизмами; Dryden имеет отдельные RMS и масштабы.

Для CustomField ручная скорость профиля не задаёт внешний пространственный источник. Seed воспроизводит математическое поле; весь Unity-полёт не гарантируется побитово одинаковым между платформами.

## Физика и визуальное отображение

Физическая среда задаёт воздух и поток, используемые силовым ядром. Визуальная погода и растительность получают согласованное отображение этого состояния. Вертикальный ветер действует на физику, хотя горизонтальный визуальный источник может его не показывать.

Нормирование скорости для визуального эффекта не обрезает физический ветер. Погодный пресет не должен добавлять вторую аэродинамическую силу. Осадки остаются метаданными и визуальным эффектом: вода, лёд и повреждения не рассчитываются.

В StandardAtmosphere профильные температура и давление имеют значение опорных атмосферных входов. Внешний `IAirProvider` может передать локальную колонку воздуха. Измеренные Ω²/RPM-кривые не масштабируются по плотности автоматически; для меняющегося воздуха используйте совместимую CtCq/PerformanceMap-модель.

## Изменение в полёте

В **F3 → Среда** можно включить ручной ветер и менять его скорость/направление в реальном времени. Он подменяет текущий запрос к источнику ветра. После отключения ручного режима возвращается исходный профиль или провайдер. Выключенный модуль `windInteraction` сохраняет своё действие.

Температура, давление, плотность и осадки в этой панели показывают применённое состояние и доступны для чтения. Остальные погодные настройки задаются до запуска в редакторе профиля.

## Сохранение и интеграция

Измените нужные значения, сохраните профиль и используйте его при следующем запуске. Профиль проверяется совместно с выбранным аппаратом. При отмене несохранённые изменения не должны менять сохранённый сценарий.
