# Решение проблем

[Документация](README.md)

| Симптом | Что проверить |
|---|---|
| EXE не запускается | Полностью ли распакован ZIP; находятся ли рядом `*_Data`, `UnityPlayer.dll` и остальные файлы; соответствует ли сборка ОС |
| Unity не импортирует проект | Версию 6000.3.25f1, доступ к Git/UPM, `Packages/manifest.json`, наличие локального пакета конфигуратора |
| Сцена отсутствует | Установлены ли её ресурсы, есть ли запись в `ScenarioCatalog`, включена ли она в активный Build Profile |
| Профиль не запускается | Сообщение валидатора, число и геометрию роторов, характеристики, плотность измерений и выбранную среду |
| Аппарат не взлетает | Включены ли моторы F, подана ли тяга Space, хватает ли суммарной тяги, нет ли ограничений питания или отказа |
| Аппарат падает после отпускания Space | Включено ли H; в ручном режиме отпускание убирает команду тяги |
| Аппарат сносит при H | H удерживает высоту; для X/Z используйте J с доступным GPS |
| Поля F3/F4 мешают пилотированию | Освободите ввод Esc или щелчком по свободному месту; для редактирования поле должно быть выбрано явно |
| После Alt+Tab всё стоит | Проверьте фокус окна и меню паузы; потеря фокуса приостанавливает симуляцию |
| В F5 WASD двигает камеру | Это управление планировщика; для ручного пилотирования переключитесь в другой полётный режим |
| Маршрут прекратился | Статус и свежесть GPS, ручное вмешательство, остановку миссии; после отказа повторно включите навигацию явно |
| Прибор недоступен или карта застыла | Включение и исправность соответствующего датчика; потеря GPS прекращает новые навигационные значения |
| Модель слишком большая или повёрнута | Масштаб и ориентацию визуального объекта, физические метры и оси; не масштабируйте физический корень |
| Винт вращается вокруг неверной точки | Привязанный узел, его pivot, ось, потомков и соответствие rotorId; используйте медленный тест вращения |
| Площадь корпуса выглядит неверной | Привязаны ли винты и исключены ли они, завершён ли расчёт, корректны ли масштаб/ориентация и разрешение растеризации |
| GLB/glTF без материалов | Наличие текстур/буферов и относительных путей, поддержку материалов, шейдеры в Player |
| Модель выглядит правильно, но физика неверна | Массу, COM, инерцию, Cd и характеристики винтов; визуальный mesh не задаёт эти параметры автоматически |
| CSV таблицы не импортируется | Заголовки, обязательные поля, разделитель, конечность чисел, диапазоны, порядок и размер таблицы |
| Запись не создаётся | Право записи в `Application.persistentDataPath`, наличие свободного места и сообщение в событиях |
| Анализатор не принимает файл | Передан ли `flight.csv`, сохранён ли заголовок, подходит ли выбранный временной интервал |
| CI пишет `Stale generated package` | Пересоздайте пакеты из корня проекта, затем запустите обе команды `--check` |
| В Unity дубли классов/сборок | Не подключены ли экспортированные Physics/Demo поверх аналогичного кода в `Assets` |
