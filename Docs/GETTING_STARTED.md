# Запуск и первый полёт

[Документация](README.md) · [Возможности](FEATURES.md)

## Готовая сборка Windows

Получите ZIP сборки из комплекта проекта или опубликованного релиза. Распакуйте его целиком в папку с правом записи и запустите EXE. Не переносите отдельно исполняемый файл: Unity использует соседнюю папку `*_Data`, `UnityPlayer.dll` и другие файлы, присутствующие в архиве.

Для обычного запуска Unity Editor, .NET SDK и Python не нужны. Они используются для работы с исходниками и анализа данных. Текущая графика основана на HDRP; пригодность конкретной видеокарты и настройки качества проверяйте на целевом компьютере.

## Запуск из исходников

1. Клонируйте репозиторий вместе с `Assets`, `Packages`, `ProjectSettings` и `Distribution`.
2. Через Unity Hub установите **Unity 6000.3.25f1**. Для Windows Player добавьте соответствующий Build Support.
3. Выберите **Add project from disk** и укажите корневую папку репозитория.
4. Дождитесь установки UPM-зависимостей и импорта ресурсов. При первом открытии нужен доступ к источникам пакетов, включая Git-зависимость glTFast.
5. Откройте сцену `MainMenu` и нажмите Play.

Если отсутствуют ресурсы дополнительной сцены, сначала используйте доступную тестовую сцену. Часть сцен и визуальных ресурсов может передаваться командой отдельно; состав импортированного проекта проверяйте в каталоге сцен и Build Profiles. Процедура подключения описана в [SIMULATION_LAUNCH.md](UI/SIMULATION_LAUNCH.md).

## Первый запуск симуляции

1. В главном меню выберите **«Новая симуляция»**.
2. Выберите сохранённый дрон или встроенный образец.
3. Выберите доступную сцену и профиль окружающей среды. Для знакомства подойдут спокойные условия без ветра.
4. Запустите симуляцию. Проверка профиля выполняется до полёта; при ошибке исправьте указанные параметры.
5. Нажмите **F**, затем **Space**. После подъёма включите **H** для удержания высоты.
6. Переключитесь в **F2** для приборов, **F3** для инженерных инструментов или **F4** для графиков.

Моторы при старте выключены. Новый полёт включает все датчики с нулевым шумом, смещением и задержкой. Настройку помех выполняйте явно через инженерную панель.

## Клавиши по умолчанию

| Клавиша | Действие |
|---|---|
| F | Включить или выключить моторы |
| W / S | Тангаж вперёд / назад |
| A / D | Крен влево / вправо |
| Q / E | Рыскание |
| Space | Тяга вверх; при удержании высоты — подъём |
| Ctrl | Снижение при удержании высоты |
| Z | Переключение стабилизации и ручного режима |
| H | Удержание высоты |
| J | Удержание текущей горизонтальной позиции при доступном GPS |
| Backspace | Возврат на стартовую площадку с выключенными моторами |
| F1 / F2 / F3 / F4 / F5 | Кинематографический режим / пилот / инженерный / анализ / планирование |
| C | Переключение обычного вида и FPV |
| F10 | Назначение клавиш и настройка управления |
| Esc | Освободить поле ввода; вне ввода — меню паузы |

В F5 клавиши WASD и Q/E управляют свободной камерой. Переназначение полётных клавиш сохраняется; актуальные назначения доступны в меню управления.

В ручном режиме отпускание Space снимает команду тяги. Удержание высоты не фиксирует X/Z; для этого нужен отдельный режим J.

## Геймпад

В настройках приложения выберите геймпад и примените изменения. Правый стик задаёт крен/тангаж, левый — рыскание и подъём/снижение, правый триггер — ручную тягу. Start переключает моторы, западная кнопка — режим стабилизации, южная — удержание высоты, северная — сброс. Раскладка геймпада пока не переназначается.

При отключённом выбранном устройстве команды с него недоступны. Чтобы вернуться к клавиатуре, измените выбор в настройках.

## Ввод в инженерных панелях

Открытие F3/F4 оставляет клавиатуру у полётного управления. Чтобы изменить число или текст, щёлкните по соответствующему полю. Во время ввода полётные команды блокируются. **Esc**, щелчок по пустому месту или действие кнопки снимают ввод. После освобождения поля управление возвращается к аппарату.

Перед редактированием в воздухе удобно включить удержание высоты и позиции. Потеря фокуса окна ставит симуляцию на паузу; возврат не должен самопроизвольно выключать уже включённые моторы.
