# Физические величины и единицы

[Раздел физики](README.md) · [Формулы](PHYSICS_REFERENCE.md) · [JSON-поля](PARAMETERS.md)

Этот справочник объясняет величины. Уравнения находятся в `PHYSICS_REFERENCE.md`, точные имена полей, типы и ограничения — в сгенерированном `PARAMETERS.md`.

## Система координат и представление

Физические величины используют SI. Unity-оси: **+X вправо, +Y вверх, +Z вперёд**. Одна физическая Unity unit — метр. Позиции роторов и COM задаются в локальных осях корпуса; ветер — в мировых осях. Плечо силы отсчитывается от центра масс, а не от произвольного pivot модели.

Физический корень и его родители имеют масштаб 1. Визуальная модель может иметь отдельное преобразование. Quaternion хранится как `[x,y,z,w]`. RPM — об/мин; внутренние угловые скорости — рад/с. Температура модели — K; UI может показывать °C.

## Тело и движение

| Величина | Обозначение / единица | Смысл |
|---|---|---|
| Общая масса | m, кг | Масса аппарата уже включает привод; роторы не добавляются повторно |
| Габариты | d, м | Физические размеры; используются в AutoBox и упрощённой геометрии |
| Центр масс | COM, м | Локальное положение центра массы |
| Тензор инерции | I, кг·м² | Распределение сопротивления угловому ускорению |
| Главные моменты | I₁/I₂/I₃, кг·м² | Инерция вдоль главных осей |
| Ориентация главных осей | Quaternion | Поворот главного базиса относительно корпуса |
| Плечо силы | r, м | Вектор от COM к точке приложения |
| Скорость | v, м/с | Поступательное движение тела |
| Угловая скорость корпуса | Ω, рад/с | Вращение тела, не обороты винта |
| Сила | F, Н | Вектор воздействия на тело |
| Момент | τ, Н·м | Вращающее воздействие |
| Гравитация | g, м/с² | Ускорение свободного падения |
| Шаг физики | Δt, с | Интервал одного вычислительного шага |

## Ротор и аэродинамика

| Величина | Обозначение / единица | Смысл |
|---|---|---|
| Ось тяги | a, безразмерная | Нормализованное направление силы ротора |
| Вращение | CW/CCW | Направление вращения и связанный знак реакции |
| Скорость ротора | ω, рад/с; RPM, об/мин | Скорость вращения отдельного ротора |
| Команда двигателя | 0…1 | Доля целевых максимальных оборотов, не линейная доля тяги |
| Тяга | T, Н | Сила вдоль оси винта |
| Момент винта | Q, Н·м | Аэродинамическая нагрузка на привод |
| Квадратичный коэффициент тяги | kT, Н/(рад/с)² | Размерный коэффициент Ω²-модели |
| Квадратичный коэффициент момента | kQ, Н·м/(рад/с)² | Размерный коэффициент момента Ω²-модели |
| Диаметр / шаг винта | D / pitch, м | Геометрия винта; шаг не заменяет измеренную характеристику |
| Коэффициенты винта | Ct, Cq, Cp, безразмерные | Разные коэффициенты тяги, момента и мощности; Cp не подставляется вместо Cq |
| Параметр осевого потока | J, безразмерный | Режим винта относительно осевого воздуха |
| Постоянная времени | tauUp/tauDown, с | Отклик набора и снижения оборотов |
| Инерция ротора | Jr, кг·м² | Вращающаяся масса привода/винта |
| Воздушная скорость | vAir, м/с | Скорость тела относительно локального воздуха |
| Площадь проекции | A, м² | Силуэт корпуса по направлению потока, не площадь всей поверхности |
| Коэффициент сопротивления | Cd, безразмерный | Аэродинамический коэффициент, требующий данных или оценки |
| Поле площадей | LUT, м² | Направления и соответствующие площади; результат геометрического расчёта |
| Ground effect / flow corrections | Безразмерные поправки | Ограниченные приближения, а не отдельная CFD-модель |

## Воздух и ветер

| Величина | Единица | Смысл |
|---|---|---|
| Плотность ρ | кг/м³ | Масса воздуха на единицу объёма |
| Температура T | K | Температура воздуха; символ T здесь не тяга |
| Давление p | Па | Статическое атмосферное давление |
| Высота h | м | Высота в атмосферной модели с заданной опорной точкой |
| Ветер w | м/с | Мировой вектор потока |
| Интенсивность порыва | м/с | Дополнительное усиление выбранной модели |
| Временной масштаб | с | Длительность/период характерного изменения |
| Seed | Целое число | Инициализация воспроизводимого математического поля |
| RMS σ | м/с | Среднеквадратичное возмущение по компоненте |
| Масштаб Dryden L | м | Пространственный масштаб спектра |
| Волновое число k | рад/м | Пространственная частота гармоники |
| Скорость переноса Ua | м/с | Перенос замороженного поля |
| Nyquist ratio | Безразмерный | Диагностика достаточности шага для выбранного спектра |
| Осадки | мм/ч и тип | Метаданные/визуальные входы; не масса воды на аппарате |

## Питание и тепло

| Величина | Обозначение / единица | Смысл |
|---|---|---|
| Напряжение | V, В | Потенциал питания при текущей нагрузке |
| OCV | Voc, В | Напряжение холостого хода как функция SOC |
| Ток | I, А | Ток батареи или отдельного элемента; не тензор инерции |
| Сопротивление | R, Ом | Эффективные потери батареи/мотора |
| Ёмкость | Ah, А·ч | Электрическая ёмкость, не готовая длительность полёта |
| Состояние заряда | SOC, 0…1 | Нормированная доступная доля заряда |
| Motor Kv | об/мин/В | Связь скорости с напряжением |
| Motor Kt | Н·м/А | Связь момента с током |
| Ток холостого хода | I0, А | Эффективная часть потерь привода |
| Мощность | P, Вт | Скорость передачи или потерь энергии |
| Энергия | E, Дж | Накопленная/переданная энергия за интервал |
| Эффективность | η, 0…1 | КПД выбранного элемента модели |
| Теплоёмкость узла | Cth, Дж/K | Энергия для изменения температуры узла |
| Теплопроводность к воздуху | G, Вт/K | Эффективный теплообмен |
| Температурный коэффициент R | α, 1/K | Изменение сопротивления мотора с температурой |
| Derating | 0…1 | Ограничение доступного привода из-за температуры |

## Контракт и происхождение

`parameterProvenance` различает измеренные значения, опубликованную модель, расчёт и оценку. `derived` содержит производную/справочную информацию; рабочие силы и инерцию определяют соответствующие физические поля.

Датчики имеют собственные оси, единицы и времена: [руководство оборудования](https://github.com/ElecTriKusX/DroneLab/blob/main/Docs/SENSORS.md). Их частота не равна шагу физики или интервалу CSV.
