2026-10-04: пользователь подтвердил работу физики. Равные RPM при установившемся
наклоне/yaw объяснены текущей моделью; добавлены ориентиры метра и измеримая телеметрия.
Ожидаемые величины и новые проверки описаны в BEHAVIOR_BASELINE.md.

Ни один optional-модуль не включаем только ради галочки. До реализации закрепляем
формулу, единицы коэффициентов, область применимости, источник данных и тесты.
Для общего allocator hex/octo отдельно потребуется распределение с ограничениями;
первый QuadAllocator нельзя рекламировать как универсальный контроллер мультироторов.

Сенсоры/шум, thermal model, GLB import, cinematic UI и отчёт — интеграционные задачи;
они не реализованы первым физическим коммитом. Параметры датчиков и регуляторов будут
отдельными контрактами, без смешивания с массой и аэродинамикой аппарата.
