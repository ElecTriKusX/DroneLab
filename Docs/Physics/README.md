# Физика DroneLab

[Документация проекта](https://github.com/ElecTriKusX/DroneLab/blob/main/Docs/README.md)

Раздел описывает физическое ядро и его доказательную базу. Пользовательские действия в конфигураторе, датчики, графики и запись вынесены в руководства приложения.

## Состав

**Physics SDK 0.3.4**, **JSON-контракт 1.0.0**, **физический CSV 1.4.0**. Версии относятся к разным интерфейсам.

Чистое C#-ядро рассчитывает силы, моменты, состояния роторов, питание и тепло. Unity-адаптер передаёт результат в Rigidbody/PhysX для интегрирования тела и контакта. Профиль выбирает модели и включает дополнительные эффекты.

| Категория | Что описано |
|---|---|
| Корпус | Масса, центр масс, главные моменты и оси инерции, силы и моменты |
| Роторы и привод | Характеристики тяги/момента, таблицы и карты, отклик, инерция, гироскопический момент |
| Аэродинамика | Корпус, mesh-проекции, поверхности и приближённые эффекты роторов |
| Среда | Воздух, плотность, ветер, порывы, турбулентность, DrydenFrozen |
| Электрика и тепло | Ограничения питания, разряд, потери, нагрев, охлаждение, derating |
| Управление | PID, распределение тяги, горизонтальный контур и маршрутные цели приложения |

## Как читать

Для настройки профиля начните с величин и реестра параметров. Для понимания расчёта откройте справочник формул. Для оценки точности используйте валидацию: согласование стендовой характеристики не подтверждает всю траекторию и каждый эффект.

Для разработки сначала прочитайте формулы, параметры и валидацию. Неизвестные коэффициенты необходимо обозначать как оценочные. Включение дополнительной модели требует совместимых входных данных; отсутствующие параметры не заменяются молча якобы измеренными значениями.
