# ДРОНЛАБ — лаборатория симуляции БПЛА

**DroneLab** — интерактивная лаборатория для настройки мультироторных аппаратов, полётов в изменяемой среде и анализа результатов. Проект объединяет собственное физическое ядро, конфигуратор дрона, несколько сцен, датчики, маршрутное управление, инженерную визуализацию и запись испытаний.

Проект разработан для кейса Инфотеха. Его основной сценарий: **создать или выбрать аппарат → настроить среду → выполнить полёт → увидеть причины поведения → сохранить данные испытания**.

## Что можно сделать

| Возможность | Что реализовано |
|---|---|
| Собрать свой дрон | Масса, центр масс, инерция, размеры, расположение и направление роторов, винты, привод, питание и физические модули |
| Использовать готовый аппарат | Встроенные образцы DJI Mavic 3, Mini 3, Avata 2 и шестироторный Matrice 600; параметры этих образцов приближённые |
| Импортировать модель | GLB/glTF, настройка масштаба и ориентации, дерево объектов, привязка частей винтов и переносимый ZIP-комплект |
| Рассчитать геометрию | Проекционные площади корпуса из mesh; автоматический пересчёт после изменения модели, исключение привязанных винтов |
| Летать в разных условиях | Несколько сцен, профили погоды и времени суток, температура, давление, плотность воздуха, ветер, порывы и турбулентность |
| Управлять аппаратом | Клавиатура и геймпад, ручной полёт, стабилизация, удержание высоты и позиции, маршрут по пользовательским точкам |
| Изменять условия в полёте | Ручная настройка ветра, параметров оборудования и контроллера в инженерной панели |
| Смотреть полёт | Кинематографический режим, экран пилота, FPV и свободная камера планировщика |
| Видеть физику | Векторы тяги, веса и сопротивления, направление ветра, траектория, луч дальномера и поле зрения камеры |
| Исследовать измерения | GPS, IMU, магнитометр, барометр, дальномер и камера; частота, шум, смещение, задержка и отключение датчиков |
| Анализировать испытание | Графики измерений и ошибок, телеметрия, события, CSV физики и датчиков, JSON настроек и анализатор записи |

Полное описание функций и их границ: [возможности проекта](Docs/FEATURES.md).

## Быстрый запуск

### Готовое приложение

Командой подготовлены сборка Windows и видеодемонстрация. Место публикации файлов — [GitHub Releases](https://github.com/ElecTriKusX/DroneLab/releases); в комплекте сдачи сборка может передаваться отдельным ZIP.

1. Распакуйте **весь** архив сборки в одну папку и запустите EXE. Папка с данными и библиотеки должны оставаться рядом с ним.
2. Откройте **«Новая симуляция»**, выберите дрон, сцену и профиль среды.
3. Нажмите **F** для включения моторов, **Space** для подъёма, **H** для удержания высоты.
4. Используйте **F1–F5** для переключения режимов. В **F4** доступны графики и запись испытания.

У нового полёта датчики включены без шума, смещения и задержки. Поля в F3/F4 получают клавиатуру после щелчка; **Esc** или щелчок по свободному месту возвращает управление дроном.

Все действия, клавиши и установка: [руководство по запуску](Docs/GETTING_STARTED.md).

### Проект Unity

Нужна **Unity 6000.3.25f1**. Репозиторий использует **HDRP 17.3.0**, UI Toolkit, Input System и glTFast. Откройте корень проекта через Unity Hub, дождитесь импорта зависимостей и запустите сцену `MainMenu`. Инструкции для сборки и форка находятся в [руководстве разработчика](Docs/DEVELOPMENT.md).

## Пять режимов полёта

| Клавиша | Режим | Назначение |
|---|---|---|
| F1 | Кинематографический | Чистый кадр и плавное сопровождение аппарата |
| F2 | Пилот | Приборы, карта фактического маршрута, статусы датчиков; **C** переключает FPV |
| F3 | Инженерный | Контроллер, оборудование, ручной ветер и векторы |
| F4 | Анализ | Телеметрия, графики, ошибки измерений, события и экспорт |
| F5 | Планирование | Свободная камера, создание точек маршрута, запуск и остановка миссии |

Маршрут выполняется через контроллер и реальные силы роторов. Планировщик не переносит аппарат по заданной линии напрямую. Подробнее: [режимы и управление](Docs/UI/FLIGHT_VIEWS_F1_F2.md).

## Физика и принятые решения

Физическое ядро написано на C# и отделено от Unity. Адаптер переводит рассчитанные силы и моменты в `Rigidbody`, который отвечает за движение твёрдого тела и контакт со сценой. Контроллер, датчики и интерфейс образуют отдельные слои.

Основные категории моделей:

- **Тело:** шесть степеней свободы, масса, центр масс, главные оси и моменты инерции, импорт CAD-тензора.
- **Роторы:** тяга и реактивный момент, коэффициентные и измеренные табличные характеристики, RPM/J-карты, отклик привода, инерция ротора и гироскопический момент.
- **Аэродинамика:** сопротивление корпуса и роторов, проекции mesh, поверхности давления, приближённые ground effect, flapping и translational lift.
- **Среда:** воздух, высота, воспроизводимый ветер, порывы, турбулентность и DrydenFrozen.
- **Энергия:** электрические ограничения, просадка напряжения, разряд, нагрев, охлаждение и ограничение тяги.
- **Управление:** каскадные PID и распределение тяги для управляемых мультироторных схем с четырьмя и более роторами.

Модули включаются профилем: поддержка модели в ядре не означает, что она включена у каждого аппарата. 3D-модель даёт геометрию и проекционные площади, но не определяет автоматически массу, Cd или характеристики двигателя. Один источник воздуха и ветра используется согласованно, без повторного приложения сил.

Формулы, единицы, контракт и численная валидация собраны в [разделе физики](Docs/Physics/README.md). Подробная архитектура: [ARCHITECTURE.md](Docs/ARCHITECTURE.md).

## Проверки и область применения

Для параметров, математических моделей, датчиков, конфигуратора и экспорта предусмотрены автоматические тесты. CI проверяет ядро и пакеты на Windows и Ubuntu. Численные сравнения отдельных характеристик с опубликованными стендовыми данными приведены в [VALIDATION.md](Docs/Physics/VALIDATION.md); они не являются оценкой точности всей траектории.

Текущая версия подходит для демонстраций, параметрических экспериментов и подготовки сценариев испытаний. Профили с оценочными параметрами требуют калибровки для сравнения с конкретным реальным аппаратом. CFD, полноценный оцениватель состояния, обход препятствий и прикладные миссии относятся к [дальнейшему развитию](Docs/ROADMAP.md).
