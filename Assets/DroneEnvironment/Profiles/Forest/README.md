# Forest: освещение и туман HDRP

[Модуль среды](../../README.md) · [Сцены и окружение](../../../../Docs/UI/SCENARIOS_AND_ENVIRONMENT.md)

Эта папка содержит настройки визуального окружения Forest. Они управляют светом, небом, туманом и погодными переходами; физический воздух и ветер имеют отдельный контракт.

## Освещение

Используйте погодный контроллер сцены и соответствующие Forest-пресеты. Должен работать один согласованный источник направленного света; второй Directional Light или конкурирующий volume могут исказить кадр.

| Параметр | Настройка профиля | Смысл |
|---|---|---|
| Scene Exposure | 10 EV | Увеличение уменьшает яркость кадра |
| Light Intensity HDRP | 10 000 | Множитель прямого света; итог также зависит от кривых и погоды |
| Sky Exposure HDRP | 11 EV | Управляет яркостью неба и заполнением теней |
| Sky Ambient Mode HDRP | Dynamic | Обновление фонового освещения по состоянию неба |
| Control HDRP Fog / Volumetrics | Включены | Управление объёмным туманом HDRP |
| Fog Base Height / Max Height | 24,1 / 98,7 м | Нижняя и верхняя высоты слоя |

Экспозиции являются настройками сцены, а не фотометрической калибровкой. Сравнивайте прямой свет, небо и экспозицию камеры при разном времени суток. MicroShadowing, ContactShadows и HDShadowSettings находятся в volume-профиле Forest.

## Погодные переходы

Переход погоды может заменить параметры тумана. Сохраняйте нужные значения также в соответствующем погодном пресете, а не только в текущем состоянии сцены.

| Пресет | Fog Attenuation Distance, м |
|---|---:|
| Clear Sky | 800 |
| Cloudy 1 | 600 |
| Cloudy 2 | 400 |
| Cloudy 3 | 300 |
| Cloudy 4 | 250 |
| Foggy | 80 |
| Rain | 180 |
| Storm | 100 |
| Snow | 150 |

Высоты слоя сохраняются 24,1/98,7 м, множители ambient/direct volumetric lighting — 1. Туман рассчитывается HDRP; конкурирующий дополнительный height fog должен оставаться выключенным также в настройках качества, которые могут повторно применяться во время исполнения.

## Сохранение и проверка

Сохраните изменённые модули в Forest-пресеты и сохраните сцену. В Play Mode проверьте детали Terrain, свет в тенях, переходы Clear Sky → Foggy → Rain → Cloudy 1 и сохранение высот тумана. Затем проверьте тот же переход в Player.

Значения таблиц описывают сохранённые настройки. Визуальный результат зависит от камеры, качества, активных volume и версии рендера; проверка YAML или GUID не заменяет просмотр сцены.
