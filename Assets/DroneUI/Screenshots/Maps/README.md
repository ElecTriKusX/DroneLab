# Превью сцен и погоды

[Сцены и окружение](../../../../Docs/UI/SCENARIOS_AND_ENVIRONMENT.md) · [Интеграция сцены](../../../../Docs/UI/SIMULATION_LAUNCH.md)

Здесь хранятся PNG/JPG-превью с пропорцией **16:9**. Назначайте Texture2D в `ScenarioCatalog` как screenshot карты или погодного пресета.

Для сцен используйте реальные снимки соответствующего окружения. `Forest.png` и `PhysTest.png` используются при первоначальном добавлении сцен. Для новой сцены добавьте изображение и его Unity `.meta`, затем назначьте ссылку в каталоге.

Название и размеры сцены задаются отдельно; размеры — в метрах. Превью не определяет рельеф, погоду или физические условия и не заменяет включение сцены в Build Profile.
